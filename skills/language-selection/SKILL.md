---
name: language-selection
description: Determine the best language or languages for a project based on technical requirements. Use when the user says language-selection, asks which language to use, or wants to reason through the best technical fit.
---

<objective>
Decide the best language or languages for the project. Do not default to a specific language just because it is easy; reason through the requirements and choose the absolute best technical fit for the project's goals.
</objective>

<process>

1. Analyze the project objectives, performance requirements, and ecosystem needs.
2. Evaluate candidate languages based on:
   - Technical superiority for the specific use case
   - Runtime performance, memory efficiency, and scalability
   - Availability of critical libraries and tooling
   - Long-term maintainability and developer ergonomics
3. If multiple languages are needed (polyglot architecture), explicitly define the boundary and communication protocol between them.
4. Present the final decision with a technical justification explaining why this choice is superior to common alternatives.

</process>
