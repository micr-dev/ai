# Foundry search sources

Read this roster when a brief calls for paid, boutique, brand, logo, or independently drawn type, or when `moji` does not produce a strong field. These are discovery seeds, not licensing authorities. Verify each finalist on its current official family and license pages.

## Directories and marketplaces

- [Type Foundry Directory](https://typefoundry.directory/) - broad independent-foundry discovery
- [Type Department](https://type-department.com/) - multi-foundry font marketplace
- [Future Fonts](https://www.futurefonts.com/) - in-progress releases whose scope and price can change as families develop
