# Source Index

Primary sources checked when creating this skill:

- GitHub Docs, "Creating diagrams": GitHub supports Mermaid in Markdown through fenced `mermaid` code blocks and documents the `info` version probe.
  - https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams
- Mermaid syntax reference: diagram declarations, comments, frontmatter configuration, directives, layout/look, and common breaking tokens.
  - https://mermaid.js.org/intro/syntax-reference.html
- Mermaid flowchart syntax: directions, shapes, subgraphs, classes, markdown strings, link styling, interactions, ELK caveats, and common parser breakers.
  - https://mermaid.js.org/syntax/flowchart.html
- Mermaid sequence diagram syntax: participants, actors, boxes, arrows, activations, notes, loops, alternatives, parallel blocks, critical blocks, breaks, and comments.
  - https://mermaid.js.org/syntax/sequenceDiagram.html
- Mermaid ER diagram syntax: crow's-foot cardinality, identifying vs non-identifying relationships, attributes, aliases, direction, and classes.
  - https://mermaid.js.org/syntax/entityRelationshipDiagram.html
- Mermaid state diagram syntax: transitions, start/end, composite states, choices, forks, joins, concurrency, notes, directions, and classDef limitations.
  - https://mermaid.js.org/syntax/stateDiagram.html
- Mermaid GitGraph syntax: commits, branches, checkout/switch, merge, tags, commit types, and branch theme limits.
  - https://mermaid.js.org/syntax/gitgraph.html
- Mermaid C4 syntax: C4 support is experimental, has fixed styling, layout is controlled by statement order and `UpdateLayoutConfig`, and some C4-PlantUML features remain unsupported.
  - https://mermaid.js.org/syntax/c4.html
- Mermaid timeline syntax: timeline is experimental, supports sections and time/event rows, with newer direction support dependent on Mermaid version.
  - https://mermaid.js.org/syntax/timeline.html
